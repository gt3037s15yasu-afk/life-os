GitHub・MCP・AI環境構築マスターガイド Ver.2.0

更新日: 2026-07-25

目的

VS Code・GitHub・GitHub MCP Server・Claude Code・ChatGPTを連携し、 AIを活用した開発・知識管理・ライフOS基盤を構築する。

全体構成

ChatGPT
   │
   ├─ Gmail / Google Calendar / Google Drive
   │
   ├─ GitHub
   │      │
   │      └─ GitHub MCP Server
   │               │
   │         Claude Code
   │               │
   └───────── VS Code

STEP1 VS Code

  • 最新版をインストール
  • Gitをインストール
  • GitHubへサインイン

STEP2 GitHubリポジトリ

  • ライフOS用リポジトリ作成
  • README作成
  • VS CodeからClone

STEP3 GitHub MCP Server（最新版）

アップデート: GitHub公式ではOAuth認証を利用できる環境では、 PATよりOAuthが推奨される構成が増えています。PATが必要な環境では従来どおりPersonal Access Tokenを利用します。

方式推奨用途
OAuth★★★★★対応環境で第一候補
PAT★★★★☆互換性重視・従来構成

OAuthの場合

  1. GitHub MCP Serverを追加
  2. Sign in with GitHub
  3. ブラウザ認証
  4. 接続確認

PATの場合

  1. GitHub → Settings → Developer settings
  2. Personal Access Tokenを作成
  3. 必要最小限の権限を付与
  4. MCP設定へ登録

STEP4 Claude Code

  • 最新版へ更新
  • MCPサーバー認識確認
  • GitHubリポジトリへアクセスできることを確認

STEP5 ChatGPT

  • GitHub連携
  • Google Workspace連携
  • 必要に応じてOutlook連携

5. 再構築の完全手順

現在は再実行不要：すでにgithub: ✔ Connectedまで成功している。ここはPATの期限切れ・削除・Mac買替え・設定破損時の再現用。
0まず現状確認
cd ~/life-os
claude mcp list
✔ Connectedなら停止：再設定しない。そのまま「6. 接続・動作確認」へ進む。
1Fine-grained PATを作る
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens。
  2. Generate new tokenを押す。
  3. Token name：Claude Code MCP
  4. Expiration：90 days
  5. Repository access：Only select repositories → life-os
  6. Repository permissions：Contents＝Read and write
  7. Metadata＝Read-only（通常は自動）
  8. Generate tokenを押し、一度だけ表示されるPATをコピー。
絶対禁止：PATをChatGPT、Claude Codeの>、README、HTML、GitHub、スクリーンショットへ貼らない。
2Apple「パスワード」へ保存
  1. ⌘＋Space → 「パスワード」を開く。
  2. ＋で新規項目を作る。既存GitHubログインは編集しない。
  3. Webサイト：github.com
  4. ユーザ名：Claude Code MCP PAT
  5. パスワード欄：PATを貼付け。
  6. メモ：life-os限定／Contents R&W／期限
  7. 保存後、普通の文字をコピーし、クリップボード上のPATを上書き。
3古いgithub設定を削除

%が見える通常ターミナルで実行する。

cd ~/life-os
claude mcp remove github

No github MCP server is currently configuredなら、すでに削除済み。次へ進んでよい。

4PATを一時変数へ非表示入力
read -s "GITHUB_PAT?PATを貼り付けてEnter（非表示）: "; echo

Apple「パスワード」からPATをコピーし、この入力待ち画面で貼り付けてReturn。文字も●も表示されないのが正常。

[[ -n "$GITHUB_PAT" ]] && echo PAT_OK || echo PAT_MISSING

PAT_OKなら成功。PAT_MISSINGなら、再度コピーしてこの手順だけやり直す。

5Claude CodeへGitHub MCPを登録

今回、Claude Code v2.1.216で実際に成功した形式：

claude mcp add-json github '{"type":"http","url":"https://api.githubcopilot.com/mcp/","headers":{"Authorization":"Bearer '"$GITHUB_PAT"'"}}'

登録後、シェル上の一時変数を消し、接続状態を確認する。

unset GITHUB_PAT
claude mcp list
成功表示：github: https://api.githubcopilot.com/mcp/ (HTTP) - ✔ Connected
重要な補足：非表示入力はターミナル画面や履歴への露出を減らす方法。PATを含むAuthorizationヘッダーはClaude Codeのローカル設定に保存されるため、Macのログイン・ディスク・バックアップも保護する。設定ファイルをGitHubへCommitしない。

8. PATの安全ルール

必ずやる

  • Fine-grained PATを使う
  • 対象Repositoryをlife-osだけにする
  • 有効期限を設定する
  • 必要最小限の権限だけ付ける
  • Apple「パスワード」に保存する
  • 期限前または不要時に失効する

絶対にしない

  • ChatGPTの会話へ貼らない
  • Claude Codeの会話欄へ貼らない
  • README・HTML・メモへ直書きしない
  • GitHubへCommitしない
  • スクリーンショットへ映さない
  • 会社用と個人用Repositoryを混ぜない
最優先ルール：「PATが漏れたかもしれない」と思った時点で、事実確認より先に失効する。再発行の手間より漏えいリスクの方が大きい。
